# Application Screenshots

This document describes the key screens and features of the WhatsApp Message Scheduler.

## 1. QR Code Authentication Screen

When you first open the application, you'll see the QR Code authentication screen:

**Features:**
- Large, clear QR code for easy scanning
- Auto-refresh functionality (updates every 3 seconds)
- Loading indicator while waiting for QR code
- Success message when connection is established
- Connection status indicator

**How to use:**
1. Open the application in your browser
2. Wait for the QR code to appear
3. Open WhatsApp on your phone
4. Go to Settings > Linked Devices > Link a Device
5. Scan the QR code displayed on screen
6. Wait for the "WhatsApp Connected!" message

## 2. Contact Selection Screen

After successful authentication, you'll see your WhatsApp contacts:

**Features:**
- Alphabetically sorted contact list
- Search functionality to filter contacts
- Contact avatars with initials
- Contact names and phone numbers
- Responsive card layout
- Smooth hover effects

**How to use:**
1. Use the search bar to find a specific contact
2. Click on any contact to schedule a message

## 3. Message Scheduling Form

When you select a contact, you'll see the message scheduling form:

**Features:**
- Contact information display at the top
- Large text area for message composition
- Date picker (with minimum date set to today)
- Time picker for scheduling
- Back button to return to contacts list
- Clear validation messages
- Disabled submit button while processing

**How to use:**
1. Type your message in the text area
2. Select the date you want to send the message
3. Select the time you want to send the message
4. Click "Schedule Message"
5. Wait for confirmation

## 4. Scheduled Messages List

View all your scheduled messages in one place:

**Features:**
- List of all scheduled messages
- Status badges (pending, sent, failed)
- Message preview
- Scheduled date and time display
- Delete button for pending messages
- Error messages for failed sends
- Auto-refresh every 30 seconds
- Sorted by scheduled date (newest first)

**Status Indicators:**
- 🟡 **Pending** (Yellow) - Message is waiting to be sent
- 🟢 **Sent** (Green) - Message was successfully delivered
- 🔴 **Failed** (Red) - Message failed to send (with error details)

## 5. Tab Navigation

The application has two main tabs:

- **Schedule Message** - Select a contact and schedule a new message
- **My Scheduled Messages** - View all scheduled messages and their status

## Color Scheme

The application uses a clean, modern color scheme:

- Primary: Blue (#3B82F6)
- Success: Green (#10B981)
- Warning: Yellow (#F59E0B)
- Error: Red (#EF4444)
- Background: Gradient from blue to indigo
- Cards: White with subtle shadows

## Responsive Design

The application is fully responsive and works on:

- Desktop computers (1920px and above)
- Laptops (1366px - 1920px)
- Tablets (768px - 1365px)
- Mobile phones (below 768px)
